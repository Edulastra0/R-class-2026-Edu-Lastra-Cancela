Q3. Grafico de Puntos de Grosor y Volumen

plot(
  trees$Girth ~ trees$Volume,
  type = "p",                   
  col = "magenta",             
  lwd = 2,                     
  xlab = "Volumen",  
  ylab = "Grosor", #y-axis 
  main = "Relación entre Volumen y Grosor de Arbolitos"
  )

Q4. Shapiro-Wilk para volumen

shapiro.test(trees$Volume)
## 
##  Shapiro-Wilk normality test
## 
## data:  trees$Volume
## W = 0.88757, p-value = 0.003579

##p-value < 0.05 asi que no es normalmente distribuido

Q5. Shapiro-Wilk para Grosor

shapiro.test(trees$Girth)
## 
##  Shapiro-Wilk normality test
## 
## data:  trees$Girth
## W = 0.94117, p-value = 0.08893

##p-value > 0.05, asi que si esta distribuído normalmente (aunque no lo parece en el histograma)
